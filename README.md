# 한국형 타임머신 시뮬레이터 (v2.3.3)

계획한 진입가·손절가·목표가를 **과거 실제 봉 데이터의 수익률 분포로 10,000번 다시 걸어보는** 독립 웹앱입니다.
2단계에서 **실시간 5분봉 검색 UI**와 **GitHub Pages 공개 배포**, **Supabase Edge Function `stock-bars` 중계 서버**를 붙였고(실시간 검색은 v2.3.0에서 화면에서 제외 — 아래 「실시간 검색을 뺀 이유」),
v2.1에서 **`[최종 해석 리포트]` 탭**(흔들림 온도계·9조합 비교·20회 생존 시뮬레이션·용어 풀이)과
**입력 데이터 엄격 검증**(고가<저가·범위 밖 시·종가·0 이하 가격·음수 거래량·중복/역순 시각 차단)을 추가했고,
v2.1.1에서 **온도계 수치 표현(± 제거·일중 고저폭)**·**매도 수량 라벨(가정 포지션 금액)과 공매도 한계 고지**·
**파서 엄격 검증(실제 달력 날짜/시각·엄격 숫자·세션별 봉 시각 배열 일치)**·**실시간 검색 대기 상태 상시 표시**를 반영했고,
v2.1.2에서 **온도계 배율 방향(남은 구간은 '내 손절의 N배', 배지는 '손절 ÷ 남은 구간')**·**시각 엄격 전체 매칭(`09:00x` 차단)과 봉 간격 판별(`5분봉`/`불규칙 봉`)**·
**조합 개수 동적 표기(중복 제거 시 `3개 조합`)**·**원본 시세 링크 포함 모든 터치 요소 44px 이상**을 반영했고,
v2.1.3에서 **매도 R 설명 부호 교정(`1R = |진입가 − 손절가|`, 매도는 `손절가 − 진입가`)**·**극단 입력 표기(`100,000원 / 99,999.99원` · `0.00001%` · `<0.01배`)와 생존 시뮬레이션–수량 카드 위험률 정합(유효 위험률)**·
**'승률' → '이익 마감률' 및 '평균 R(기댓값) 우선' 토글 정확화**·**요약 2줄 '미도달 포함' 보강**·**오류 문구 단어 단위 줄바꿈**을 반영했고,
v2.2.0에서 **초등학생 눈높이 쉬운 리포트**로 개편했습니다 — 맨 위 **신호등 3줄 결론**(🔴/🟡/🟢 + 평균 금액 기준, 100번 기준 횟수·원화),
섹션 제목·문장의 1:1 쉬운 말 번역(하루 흔들림·손절·목표 조합·100명 중 내 돈·몇 주), 수학적 근거는 접이식 **`숫자·전문 산식 자세히 보기`**로 분리,
각주 12px 이상·대비 강화·극단 입력 Y축 `100·100·100` 겹침 해소.
v2.2.1에서 4호 봇이 지적한 결함 4건을 고쳤습니다 — **극단 입력은 🟢 대신 ⚪ `참고하기 어려워요`(중립 회색)** 로 판정을 보류하고 이유(실제 체결·수수료 오차)를 적으며,
**계산 수량 0주면 생존 시뮬레이션도 위험률 0(100 유지, 시작 자금 아래 확률 0%)** 으로 수량 카드와 일치시키고,
**매수↔매도 방향 전환·손익비 프리셋이 소수 가격의 0.01 정밀도를 보존**하며(`100,000 / 99,999.99 → 100,000.01`),
**모든 안내·각주 글꼴을 12px 이상**으로 올렸습니다.
v2.2.2에서 4호 봇이 남긴 마지막 1건 — **극단 입력에서 리포트 본문(⚪ 중립)과 시뮬레이터 화면의 불일치**를 없앴습니다:
**5초 요약 배너**의 `1회 평균 +729.07R` 을 초록 강조 대신 중립 회색으로 표시하고 `손절폭이 너무 좁아 참고하기 어려워요` 한 줄을 붙이며,
**1만 번 모의 재생 결과** 카드의 `평균 결과` 도 중립 회색 + `극단적으로 좁은 손절폭이라 숫자가 크게 보일 수 있어요` 보조 문구로 통일했습니다
(리포트 접이식 `1회 평균` 통계까지 같은 중립 색). 일반 입력의 초록/빨강 강조는 종전 그대로입니다.
v2.2.3에서 4호 봇이 남긴 2건을 마무리했습니다 — **극단 입력에서 화면 전체의 초록 강조를 끕니다**:
5초 요약 배너의 목표 도달 확률, 1만 번 결과 카드의 `목표가 먼저 도달`(녹색 카드)·`이익 마감률`, 수량 카드의 `목표에 닿으면 버는 돈`,
리포트 접이식 통계·생존 그래프 상위 10등·조합표 이익 칸·백테스트 목표 도달까지 모두 중립 회색(`.neutral`)으로 통일해
⚪ `참고하기 어려워요`와의 시각적 모순을 없앴고(손절·손실의 빨강은 사실 값이라 유지),
**0주 무포지션의 원인을 정확히 가릅니다**: `1주 위험폭 > 1회 허용 손실`이면 위험폭을, `1주 가격 > 계좌 금액`이면 계좌 금액을,
둘 다면 두 이유를 함께 실제 금액으로 적어 "손절폭이 너무 넓거나, 계좌 금액이 1주 값보다 작아요" 같은 뭉뚱그린 문구를 없앴습니다.
v2.2.4에서 4호 봇이 남긴 3건을 고쳤습니다 — **①0주와 극단 손절폭 경고를 분리**: `1번 할 때 평균(참고)` 아래 각주가 0주(무포지션)일 때도
`극단적으로 좁은 손절폭이라 참고하기 어려워요`를 붙이던 버그(진입 200,000 / 손절 199,000 = 0.5%인 정상 손절폭에서도)를 고쳐,
0주면 `0주라 1번에 거는 손절 금액이 없어 기댓값도 0원이에요`, 수량이 있고 손절폭이 정말 극단일 때만 극단 문구를 적습니다.
**②조합표 목표 배수 표기 = 실제 목표가 배수**: 열 이름이 요청 배수(1.5배)가 아니라 **그 칸에 실제로 쓰인 목표가로 다시 계산한 배수**를 가리키고,
계산용 1원 단위 반올림 때문에 요청과 달라진 열은 `＊`와 함께 칸마다 `100,002원 · 실제 2배`를 적으며, 같은 행에서 두 배수가 같은 목표가가 되면 한 번만 계산해
다른 칸은 `같은 목표가`로 표시합니다(손절 행 이름도 5% 차이를 `내 계획 그대로`로 보지 않게 0.5% 기준으로 좁힘).
**③요약 문구와 수치의 모순 제거**: 목표·손절 횟수가 같거나 둘 다 0회인데 `더 많았어요`라고 말하던 결론, 1만 번 중 40번(0.4%) 있었던 목표 도달을
`100번 해보면 … 간 경우는 없었고`라고 말하던 1줄, 횟수를 말하던 신호등 배지(`🔴 1번 평균은 손실 쪽이에요` 등 평균 기준으로),
`목표 도달 3.3% + 유리 마감 0.1%`인데 이익 마감률은 3.5%로 적히던 0.1% 반올림을 모두 바로잡았고, 5초 요약 배너에 `미도달`을 더해
세 확률의 합이 100%가 되게 했습니다.
v2.2.5에서 4호 봇이 지적한 **남은 코드 결함 3건**을 고쳤습니다 — **①0주 리포트 결론 부제 모순**: 0주(무포지션)인데도 신호등 배지 아래에 `평균 금액 기준`을 적어
(실제 건 금액 0원) 서로 모순되던 문구를, 0주일 때 `무포지션(0주) 상태 — 1회 평균 배수(R) 기준 (실제 매수 금액 0원)`으로 분기합니다(수량이 있으면 종전 그대로 `평균 금액 기준`).
**②`호가 단위` 표기 정정**: 실제 한국거래소 호가 단위는 가격대별로 다른데, 앱이 계산을 단순하게 하려고 쓰는 1원 반올림을 호가 단위처럼 적어 오해를 낳았습니다.
이제 화면·코드 어디에도 그 표기가 없고 `계산용 1원 단위 반올림 (실제 거래소 호가 단위는 가격대별로 다름)`으로 적습니다(＊표시 열 안내·중복 손절가 안내·극단 손절폭 경고·README 전부).
**③조합표 클릭 칸을 화면 판독기에 버튼으로**: 종전에는 클릭 가능한 칸에 `role="cell"`을 덮어써 버튼 역할이 사라졌습니다. 이제 표 구조(`table > row > cell`)는 그대로 두고
`cell` 안에 진짜 `<button type="button" aria-pressed>`를 두어 버튼 역할·키보드 포커스·Enter/Space 동작이 살아 있고, 터치 영역도 `44×44px` 이상입니다(포커스 테두리 추가).
v2.3.0은 사용자 지시 두 가지를 반영했습니다 — **①깨진 모바일 헤더 복구**: 종전에는 우측에 긴 버전 배지(`v2.2.5 · 0주 부제·계산용 1원 단위 표기·조합표 버튼 접근성`)를 `white-space: nowrap`으로 붙여 두어
390px·360px 화면에서 배지가 가로 폭을 다 먹고 제목 `한국형 타임머신`이 `한/국/형/타…`처럼 한 글자씩 쪼개져 4줄, 부제가 8줄로 찌그러졌습니다.
이제 배지는 **짧은 `v2.3`**(전체 설명은 마우스를 올리면 보이는 `title`)으로 줄이고 **제목과 같은 줄**(`.brand-title-row`)에 두며,
제목은 `white-space: nowrap`으로 단어 중간에서 끊기지 않습니다(자리가 모자라면 배지만 다음 줄로 내려감). 390px·360px 실측에서 제목 **1줄**, 부제 2줄입니다.
**②실시간 종목 검색 제외**: `stock-bars` 중계 호출과 `서버 토큰 연동 대기 중` 배지를 화면에서 없애 **네트워크 요청 0건**(앱은 시세 서버를 전혀 부르지 않음)으로 만들고,
입력 경로를 **내장 종목 + CSV/JSON 업로드**로 정리했습니다.

v2.3.3은 텔레그램 회의실 4호 봇이 v2.3.2(91/100)에서 남긴 3건을 고쳤습니다 —
**①CSV 레코드 구분자 CRLF + 선행 공백 수식 방어**: `toCsv` 가 줄을 `\r\n`(RFC 4180)으로 잇고, `csvCell` 은
앞쪽 공백·탭·개행 뒤에 오는 `=`,`+`,`-`,`@` 도 `'` 로 막습니다(엑셀은 칸 앞 공백을 지우고 다시 수식으로 읽습니다).
`-1000`·`  -1.5e3` 처럼 숫자인 음수는 그대로 둡니다. 내려받은 CRLF 파일을 **붙여넣기**와 **파일 선택** 두 경로로
다시 적용해 같은 데이터·같은 재생 결과가 나오는 것을 실측했습니다.
**②비활성 탭 패널 `aria-controls` 정합**: 종전에는 선택되지 않은 패널을 언마운트해 `aria-controls="panel-report"` 가
존재하지 않는 id 를 가리켰습니다. 이제 두 `role="tabpanel"`(`panel-sim`·`panel-report`)을 **항상 DOM 에 두고**
비활성 패널에 `hidden` 을 주며, `[hidden]{display:none !important}` 로 `.layout{display:grid}` 에 밀리지 않게 했습니다.
탭을 오가도 시뮬레이터 입력·결과가 그대로 남습니다(언마운트 없음).
**③CSP 메타 정책**: GitHub Pages 는 응답 헤더를 정할 수 없어 `index.html` 에
`default-src 'self'; connect-src 'self' https://api.twelvedata.com; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; base-uri 'self'; form-action 'none'; object-src 'none'`
을 걸었습니다. 빌드 산출물에는 인라인 스크립트가 없고 `eval`/`new Function` 도 쓰지 않아 `script-src 'self'` 로 충분하며,
그 상태에서 BYOK(`api.twelvedata.com`) AAPL 5분봉 수신·1만 번 재생이 정상입니다(`vite dev` 는 HMR 인라인 스크립트 때문에
`vite.config.ts` 가 개발 모드에서만 이 메타를 걷어냅니다 — 배포 정책은 `index.html` 한 곳).

v2.3.2는 텔레그램 회의실 4호 봇이 v2.3.1(85/100)에서 지적한 5건을 고쳤습니다 —
**①BYOK 키 전송 보안**: Twelve Data CORS preflight 가 `Authorization` 헤더를 허용하는 것을 실측(어 `OPTIONS` 204 +
`access-control-allow-headers: … Authorization …`, 같은 헤더로 `apikey demo` GET 200)해 **키를 URL 쿼리(`?apikey=`)에서 떼어
`Authorization: apikey <키>` 헤더로 옮기고** `referrerPolicy: "no-referrer"` + `<meta name="referrer" content="no-referrer">`로
주소·방문 기록·Referer 에 키가 남지 않게 했습니다.
**②CSV 내보내기 이스케이프**: 모든 칸에 RFC 4180 규칙(쉼표·큰따옴표·줄바꿈이면 큰따옴표로 감싸고 `"` → `""`)과
수식 인젝션 방어(`=`, `+`, `-`, `@` 선두면 `'` 부착, `-1000`·`+1.5` 처럼 숫자인 값은 제외)를 적용했습니다(`src/lib/csv.ts`).
**③custom 모드 전환**: 4단계 안내에 **[내 데이터 직접 입력으로 이동]** 버튼을 넣어 어떤 상태에서든 입력칸이 열리고 포커스를 받으며,
사용자 데이터로 돌아올 때 그 데이터 기준 기본가로 다시 맞춥니다.
**④결과 포커스**: 1만 번 재생이 끝나면 결과 제목(`role="region"`, `tabIndex=-1`)으로 키보드 포커스를 옮겨(`focus({preventScroll:true})`)
스크린리더·키보드 사용자가 바로 결과를 읽습니다.
**⑤탭 키보드 탐색**: `role="tablist"` 에 `ArrowLeft/Right`(순환)·`Home`·`End` 와 로빙 `tabIndex` 를 넣었습니다.

투자 권유·매매 신호가 아니며, 미래 수익을 보장하지 않습니다. 개인 연구·참고용 **비상업** 통계 도구입니다.


## 본인 API 키로 5분봉 불러오기 — BYOK (v2.3.1 · 키 전송 v2.3.2)

사용자 지시(“2안으로 하되 사용방법을 하나하나 가이드해주는걸 넣어줄수있어?”)에 따라,
**방문자가 자기 무료 API 키를 넣어 5분봉을 직접 받아오는 길**을 열었습니다. 중계 서버는 없습니다 —
방문자 브라우저가 시세 제공처에 **직접** 요청하고, 키는 그 요청의 **헤더에만** 붙습니다.

| 화면 순서 | 방문자가 하는 일 | 확인된 사실 (2026-11-20, 공식 문서·실응답) |
| --- | --- | --- |
| 1단계 | [Twelve Data 무료 가입](https://twelvedata.com/register) 새 탭 열기 | Basic 플랜 **월 $0**, **1분 8회·하루 800회**, 열린 시장 **3곳(미국 주식·ETF·외환·암호화폐)** |
| 2단계 | [My API Keys](https://twelvedata.com/account/api-keys)에서 키 복사 | 키는 계정 화면에서 발급·재발급 |
| 3단계 | 키·티커를 넣고 **[데이터 불러오기]** | `GET https://api.twelvedata.com/time_series?interval=5min&outputsize=5000` + `Authorization: apikey <키>` — `access-control-allow-origin: *` 이고 preflight 가 `Authorization` 을 허용해(`OPTIONS` 204) 브라우저 직접 호출이 된다. 데모 키로 AAPL 5,000봉 = **78봉 × 64일** 수신 확인 |
| 4단계 | 한국 종목은 증권사 HTS 5분봉 CSV | 무료 플랜 3개 시장에 **KRX가 없어** 한국 5분봉은 유료 플랜이 필요 — 대신 HTS CSV를 그대로 올리면 같은 계산. 이 단계에서 **[내 데이터 직접 입력으로 이동]** 버튼으로 입력칸을 바로 연다 |

- **키가 가는 곳(v2.3.2)**: 키는 `Authorization: apikey <키>` **요청 헤더**로만 시세 제공처에 갑니다.
  URL·주소창·방문 기록·Referer 에 남지 않도록 `referrerPolicy: "no-referrer"` 와 `index.html` 의
  `<meta name="referrer" content="no-referrer">` 를 함께 적용했습니다.
- **키 보관**: 기본은 메모리(새로 고침하면 사라짐). 화면의 스위치를 켤 때만 이 브라우저 `localStorage`
  (`ttm.byok.twelvedata.key.v1`)에 남기고, 스위치를 끄면 즉시 지웁니다. 사이트 서버로는 키도 데이터도 가지 않습니다.
- **오류 안내**: 잘못된 키(401) · 이 플랜에서 못 여는 종목(403, 한국 종목 포함) · 분당/일일 한도(429) ·
  없는 티커(404) · 5xx · 네트워크/차단을 각각 다른 문구로 알려 줍니다(제공처 메시지를 그대로 노출하지 않고,
  키가 응답에 섞여 와도 `***`로 가립니다).
- **데이터 모양**: 응답을 그대로 쓰지 않고, 봉 수가 정확히 같은 **완전한 하루(세션)만** 남깁니다
  (진행 중·반장·갭 세션 제외, 제외 목록은 데이터 출처 카드에 기록). 3일 미만이면 계산하지 않습니다.
- 5분봉·봉 시작 시각·세션 구간·조회 시각은 기존 내장 데이터와 같은 형식으로 `meta`에 적힙니다.

같은 이유로 **한·미 100종목 내장**은 하지 않았습니다(v2.3.0 판단 유지). 무료·공개 5분봉을 공개 사이트에
JSON으로 실어 재배포하는 것이 허용되는지 **약관별로 결론이 다르고, 유료 재배포 애드온·별도 계약이 필요한 곳이
많아** 일괄 “전부 금지”로 단정하지 않습니다(아래 표). 대신 ① 본인 키로 조회(BYOK) ② 내 CSV/HTS 내보내기
③ 저작권 쟁점이 없는 **가상 체험 데이터** 세 길로 정리했습니다.

## 화면 보조 기능 (v2.3.3)

- **동작 줄이기**: 기기에서 `prefers-reduced-motion: reduce` 를 켜면 결과로 이동할 때 부드러운 스크롤 대신
  애니메이션 없이 바로 이동합니다(시뮬레이션 후·리포트 열기 두 곳).
- **결과 포커스(v2.3.2)**: `[1만 번 모의 재생 실행]` 이 끝나면 결과 제목 영역(`role="region"`, `tabIndex=-1`)으로
  키보드 포커스를 옮기고(`focus({ preventScroll: true })`) 그 자리로 스크롤합니다.
- **탭 키보드 탐색(v2.3.2)**: `role="tablist"` 에서 `ArrowLeft`/`ArrowRight`(처음↔끝 순환)·`Home`·`End` 로
  탭을 고르고 포커스를 옮깁니다(로빙 `tabIndex`, 선택은 포커스를 따라감).
- **CSV 내보내기(v2.3.2 → v2.3.3)**: 모든 칸을 RFC 4180 으로 감싸고(쉼표·큰따옴표·줄바꿈) `=`,`+`,`-`,`@` 선두는
  수식 인젝션을 막습니다(숫자인 `-1000`·`+1.5` 는 그대로). v2.3.3부터 줄 구분자는 **CRLF** 이고, 앞쪽 공백·탭·개행
  뒤의 수식 트리거도 막습니다. 내려받은 파일을 그대로 다시 붙여넣거나 파일로 골라도 같은 데이터입니다.
- **CSP(v2.3.3)**: `index.html` 메타 CSP 로 스크립트·스타일·이미지·연결 대상을 `self`(+시세 호스트)로 제한합니다.
  인라인 스크립트와 허용 밖 호스트 연결은 브라우저가 거부합니다(실측: 인라인 차단·`example.com` 차단·`api.twelvedata.com` 허용).
- **탭 패널(v2.3.3)**: 두 패널이 항상 DOM 에 있고 비활성 패널만 `hidden` 입니다 — `aria-controls` 가 늘 실제 요소를 가리킵니다.
- **메타 설명**: `index.html` 의 `description`·`og:description` 에서 “실시간 5분봉”을 빼고, 가상 체험·내 CSV·
  내 API 키라는 실제 기능으로 적었습니다.
- **정리**: 화면에서 쓰지 않던 `StockSearch.tsx`·`stockApi.ts`·`supabase/functions/stock-bars/` 를 삭제했습니다.

## 사용자 데이터 입력

CSV/텍스트 붙여넣기 또는 파일(.csv/.txt/.json) 업로드.
- 권장 형식: `시각,시가,고가,저가,종가,거래량` (`2026-11-18 09:05,71500,71600,71300,71450,12345`)
- JSON: `[{date, time, open, high, low, close, volume}, …]` 또는 `[[시각, 시가, 고가, 저가, 종가], …]`
- 같은 날짜에 봉이 3개 이상인 분봉만 지원. 날짜만 있는 일봉은 재생 불가(안내 문구 표시).
- 봉 개수가 최빈값과 다른 날(반장·누락)은 자동 제외하고 화면에 알림.

## 터치 영역 44px (v2.1.2)

모든 클릭·터치 요소(버튼·입력·요약 토글·표 칸·`<summary>`·링크)는 높이 **44px 이상**입니다.
문장 안에 흐르던 **원본 시세 링크도 예외 없이** `display: inline-flex; align-items: center; min-height: 44px`로
바꾸고, 긴 URL은 `word-break: break-all`로 감싸 가로 넘침 없이 누를 수 있게 했습니다
(`src/styles.css`, `src/components/DataNote.tsx`). 실측: 1280/390/360 모든 화면 44px 미만 0건.
손실 한도 카드의 `기댓값 (참고치)`도 초록/빨강 대신 **중립 진회색(`#475569`)** 으로 표시하고
`과거 평균 R 단순 곱 · 수수료·세금·갭 미반영` 각주를 붙여, 수익 예상처럼 읽히지 않게 했습니다(v2.1.2).
v2.1.3에서는 각주에 **포지션 방향과 실제 사용한 평균 R**을 함께 적습니다 — `매수 가정 · 평균 −0.18R 단순 곱 · 수수료·세금·갭 미반영`처럼 표시해
3줄 요약·조합표의 평균 R과 방향을 바로 대조할 수 있습니다(`expectedValueNote`, `src/lib/terms.ts`).

## 입력 데이터 검증 (v2.1.1)

`src/lib/parseCustom.ts` 가 적용 전에 아래를 검사하고, 하나라도 어긋나면 **적용을 막고 한국어로 이유를 알려 줍니다**
(첫 3건 + `외 N건`).

- 고가 < 저가
- 시가·종가가 `[저가, 고가]` 범위 밖
- 0 이하 가격 · 음수 거래량 · 숫자로 읽지 못한 가격
- 같은 날짜·시각 중복 봉 · 시간 역순 봉
- **달력에 없는 날짜·시각**(`2026-02-30`, `2025-02-29`, `25:00`, `09:75`) — 윤년까지 계산
- **엄격한 숫자 형식**(`/^[+-]?(?:\d+\.?\d*|\.\d+)$/`): `100abc`·`1 00`·`100원`을 조용히 숫자로 바꾸지 않고 원문 그대로 지목해 차단 (천 단위 쉼표 `1,000`은 허용)
- **세션별 봉 시각(HH:MM) 배열 일치**: 봉 개수만 같은 것이 아니라 모든 거래일의 봉 시각 순서가 같아야 함(다르면 어긋난 세션·봉을 지목해 차단)
- **시각 전체 매칭(v2.1.2)**: `2026-11-01 09:00x`처럼 뒤에 잔여 문자가 붙은 시각은 `09:00`으로 통과시키지 않고 `· 시각 형식이 잘못된 값: "2026-11-01 09:00x"`로 차단합니다. `09:00`·`09:00:00`·`09:00:00.000`·`T09:00:00+09:00`·`20261101 0900`·`11/01/2026 09:00`은 그대로 읽습니다
- **봉 간격 판별(v2.1.2)**: 세션 안 연속 봉 간격이 모두 같으면 `5분봉`, 섞여 있으면(예: `09:00·09:05·10:00`) `불규칙 봉`으로 표시하고 `봉 간격이 일정하지 않습니다(5분 2회, 55분 1회)…` 경고를 붙입니다(봉 수 환산은 최빈 간격 기준)
- (경고) 봉 개수가 다른 날 제외 · 날짜를 읽지 못한 행 제외 · 표본 부족
- 역순 봉 오류 문구: `국내 HTS 기본 내보내기처럼 최신 봉부터 내려오는 CSV는 위아래를 뒤집어 시간순(오래된 봉 → 최신 봉)으로 붙여넣으면 됩니다`
- 오류가 여러 건이면 `/`로 잇지 않고 `·` 항목별 줄바꿈으로 보여 줍니다(`.alert.error{white-space:pre-line}`).

`내 데이터 직접 입력` 을 고르고 아직 [적용하기]를 누르지 않았으면 이전 종목으로 계산하지 않고
실행 버튼을 잠그며 `먼저 차트 데이터를 입력하고 [적용하기]를 눌러주세요` 를 표시합니다.
CSV/JSON은 브라우저 안에서만 처리되고 외부로 전송되지 않습니다. v2.3.1부터는 방문자가 **자기 API 키**를 넣은 경우에만
브라우저가 시세 제공처(`api.twelvedata.com`)에 직접 요청하며, v2.3.2부터 그 키는 **요청 헤더(Authorization)로만** 오갑니다
(URL·Referer·방문 기록에 남지 않음). 그때도 키·데이터는 이 사이트 서버로 가지 않습니다.
